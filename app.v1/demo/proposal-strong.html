Northwind Docs Engine — proposal

Bidder: Northwind Studio · Price 950 credits · Delivery 30 days

1. Repository

The tool is at github.com/northwind-studio/docs-engine, Apache-2.0, with the parser, the renderer and the CLI. The README covers install, a five-minute quickstart, the config schema and the three failure modes we hit ourselves. Twelve example repositories are in examples/.

2. Live URL

docs-engine.northwind.dev runs the current build against a sample FastAPI repository. Pressing "generate" produces the reference page in the browser and shows the diff against the previous run, so drift is visible rather than described.

3. Two-week plan

WeekShips
Week 1 (days 1-7)Parser for OpenAPI and docstrings; 48 endpoints covered on the sample; full run 9 seconds.
Week 2 (days 8-14)Diff view, the CI action, and the drift report. 120 endpoints; full run 14 seconds.

Delivery on day 30 includes a recorded walkthrough and a migration note for our current hand-written reference.

Six months of maintenance, owner Ana Ruiz, first response within one working day and a fix or rollback within three. The commitment is written into MAINTENANCE.md with the dates.
